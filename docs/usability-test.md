# GitSeek usability test

Use five 20-minute sessions before the first public release. Ask participants to think aloud; do not
explain the interface unless they are completely blocked.

## Tasks

1. Confirm whether the app is connected and identify which backend it uses.
2. Find a project for learning a named technology without opening advanced filters.
3. Repeat the search with a license, activity window, and project-size constraint.
4. Explain why the first result was recommended and name one risk.
5. Open a project dossier and identify a suitable contribution Issue.
6. Compare two projects and choose one.
7. Save a project and submit whether the recommendation was helpful.
8. Find the application version and check for updates.

## Record

For each task record completion, time, wrong turns, the participant's exact confusing phrase, and
severity (`blocked`, `slowed`, or `cosmetic`). Do not record API keys, repository tokens, database
URLs, or other secrets. Fix repeated blocked issues before adding new discovery features.
